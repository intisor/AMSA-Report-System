Executive Summary</strong></h1><p>The AMSA Nigeria Reporting System is a digitised monthly activity reporting platform built for the Ahmadiyya Muslim Students' Association Nigeria. It replaces the current manual workflow — where department officers fill Microsoft Word documents and submit them via WhatsApp/email chains — with a structured, web-based system that captures all report data in a database, enforces compliance thresholds, routes reports through the organisational hierarchy, and gives National leadership real-time visibility into activity across all units and states.</p><p>The system is built as a Blazor Server application backed by ASP.NET and SQL Server. It consumes the existing AMSA API as its authentication and member data layer, registering as an external app and obtaining JWT tokens with scope-based and role-based claims.</p><table><tr><td><p><strong>Core Value Proposition</strong></p><p>One structured monthly submission per unit (9 department sections) + one per state feeds a live national dashboard. No more chasing Word docs. No more manual collation. No more missing reports. Compliance flags are automatic.</p></td></tr></table><h1><strong>2. Problem Statement</strong></h1><h2><strong>2.1 Current State</strong></h2><p>Every month, each AMSA unit must report on 9 departmental areas (Taleem, Tabligh, Welfare, Sport, Finance, Health, Secondary School, Tajneed, General). The current process is:</p><ol><li>Each department officer fills a Word document template manually.</li><li>The completed document is sent to the Unit President via WhatsApp or email.</li><li>The Unit President reviews, adds a note, and forwards to the State General Secretary.</li><li>The State GS manually collates reports from every unit in their state.</li><li>The State GS then submits the state's own monthly report to the National GS.</li><li>The National GS receives dozens of Word documents and manually aggregates them.</li></ol><h2><strong>2.2 Pain Points</strong></h2><table><thead><tr><th><p><strong>Pain Point</strong></p></th><th><p><strong>Impact</strong></p></th><th><p><strong>Who Feels It</strong></p></th></tr></thead><tbody><tr><td><p>Lost/missing reports</p></td><td><p>No record of unit activity for that month</p></td><td><p>National GS, State GS</p></td></tr><tr><td><p>Late submissions</p></td><td><p>National cannot compile accurate monthly summary</p></td><td><p>National President</p></td></tr><tr><td><p>No submission visibility</p></td><td><p>State GS cannot see who has/hasn't submitted</p></td><td><p>State GS</p></td></tr><tr><td><p>No compliance tracking</p></td><td><p>Taleem 75% threshold violations go unnoticed</p></td><td><p>National Education Sec.</p></td></tr><tr><td><p>Manual aggregation</p></td><td><p>National GS spends hours combining Word docs</p></td><td><p>National GS</p></td></tr><tr><td><p>No trend analysis</p></td><td><p>Cannot identify consistently underperforming units</p></td><td><p>National President</p></td></tr><tr><td><p>Format inconsistency</p></td><td><p>Officers fill fields incorrectly or incompletely</p></td><td><p>All reviewers</p></td></tr><tr><td><p>No escalation mechanism</p></td><td><p>Challenges needing National intervention get buried</p></td><td><p>State Presidents</p></td></tr></tbody></table><h1><strong>3.
